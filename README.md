#  Registro de Mascotas  
Sistema web para registrar y gestionar mascotas, desarrollado como parte de la evaluación Final del Modulo 6.

##  Funcionalidades principales

- Registrar nuevas mascotas  
- Ver todas las mascotas registradas  
- Buscar mascota por **nombre**  
- Buscar mascotas por **RUT del dueño**  
- Eliminar mascota por **nombre**  
- Eliminar todas las mascotas asociadas a un **RUT**

##  Tecnologías utilizadas

- **Node.js + Express** — Servidor y API  
- **Handlebars** — Motor de plantillas  
- **Axios** — Comunicación frontend-backend  
- **JSON** — Base de datos local

##  Cómo ejecutar el proyecto

### 1. Clonar o descargar el repositorio

git clone https://github.com/carito914/Evaluaci-n-final-m-dulo-6.git
cd registro-mascotas


### 2. Instalar dependencias

npm install

### 3. Iniciar el servidor

npm run dev


### 4. Abrir en el navegador

http://localhost:3000
